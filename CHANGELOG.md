# Changelog

All notable changes to Eloria are listed here. The format follows [Keep a Changelog](https://keepachangelog.com), and the project uses [Semantic Versioning](https://semver.org). Each section is copied into the release notes.

## 0.3.0 · 2026-11-09

First public release.

### Write
- Markdown with live preview, cell-by-cell table editing, `![[Note]]` embeds, KaTeX math, Mermaid diagrams.
- LaTeX editor: local compilation (Tectonic, latexmk, pdflatex), PDF side by side, two-way SyncTeX, tools for formulas, tables, TikZ and cross-references; thesis assembly.
- Thesis workspace, outline generator, argument builder, academic style check, similarity check, pre-submission checklist.

### Read
- Read-only mirror of the Zotero library, import into notes without duplicates, sources and reading notes.
- Add references by DOI, title, PDF or BibTeX, with abstract and keywords; built-in PDF reader with annotations and figure capture.
- Research matrix, literature review, source reliability signals, citation network and tracking, similar articles.

### Connect
- Graph, concepts and knowledge cards, topics, entities, taxonomy, methodologies, knowledge map, research statistics.

### Optional AI
- Ask Eloria (questions, synthesis, contradictions, debate, gaps), AI-drafted reading notes, summaries, writing and scientific-writing assistants. Every cited reference exists in the vault or library.

### Make it yours
- 14 themes plus custom CSS themes, custom shortcuts, typed properties, saved views, custom commands, JavaScript extensions with a developer console, MCP server, local capture API.
- English and French interface, built-in help (`F1`).

### Distribution
- Installers for Windows (x64, ARM64), macOS (Apple Silicon, Intel) and Linux (deb, rpm, AppImage). On Windows, per-user install with the MCP server included; uninstalling keeps settings and vaults.
