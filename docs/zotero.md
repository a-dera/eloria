# Zotero in Eloria

## How it works

Eloria builds a **local mirror** of your Zotero library in the vault index (`.eloria/index.db`, tables `z_*`): items, authors, collections, tags, attachments and **PDF annotations** (highlights, notes, comments). Once synced, the library can be browsed even with Zotero closed.

Eloria **never writes** to Zotero: `zotero.sqlite` is copied to a temporary folder and read there, which also avoids the lock Zotero holds on its database while it runs.

## Two sources

| Source | When | What it provides |
|---|---|---|
| **Local database** `zotero.sqlite` (default) | Always, Zotero open or not | Everything, including annotations |
| **Local API** `http://127.0.0.1:23119/api/` | Fallback when the database cannot be found | Everything; Zotero must be running |

The automatic mode tries the database, then the API. To enable Zotero's local API: Zotero › Settings › Advanced › *Allow other applications on this computer to communicate with Zotero*.

The data folder is shown in Zotero › Settings › Advanced › Files and Folders. The default (`~/Zotero`) is detected automatically; otherwise set it in Eloria's Settings › Zotero.

## Citation keys

1. If **Better BibTeX** is installed, Eloria uses its keys (read from `better-bibtex.sqlite`).
2. Otherwise, it uses Zotero 7's `Citation Key` field, or a `Citation Key: …` line in the *Extra* field.
3. Otherwise, it generates a key `authorYearWord` (e.g. `smith2024graph`), with an `a`, `b` suffix for duplicates.

Better BibTeX is recommended: its keys are stable and match those used in Word and LaTeX.

## A typical workflow

1. Read and annotate the PDF in Zotero (coloured highlights, comments), or in Eloria's own PDF reader.
2. In Eloria, Zotero panel › sync button (or let Eloria sync automatically when Zotero changes).
3. Open the item: it becomes a **source** note in the vault. Click **Create reading note**: the note holds the metadata as properties, an analysis outline and is linked to its source.
4. Write your analysis in the sections, attach the note to chapters (`chapitres: [ch2]`) and update its status.
5. Still annotating in Zotero? Sync, then **Annotations** on the source: only the block between `<!-- zotero:debut -->` and `<!-- zotero:fin -->` is regenerated. A version is saved in the history before each regeneration. (These markers are part of the file format and keep their original names.)
6. In your chapters, cite with `[@key, p. 12]`. The right panel lists the cited references; Word/PDF export resolves citations and adds the bibliography.

## Sources and reading notes

Notes generated by Eloria follow the interface language. A **source** note holds the item's record (properties, abstract, PDF link, annotation block) and is regenerated safely: your own text is never overwritten. A **reading note** is created from a source with a fixed outline (research problem, objectives, methods, data, results, discussion, constraints, challenges, future work, key references, commentary) that you fill in, by hand or with the AI-drafted "Eloria method" note (optional, reviewed before saving).

Each annotation's Zotero colour becomes the colour of its callout. `zotero://` links open the PDF at the right page and annotation.

## Other features

- **Item view**: abstract, tags, annotations with *Insert into note* (quote, key and page) and *Show in PDF*, notes of the vault that cite it, full record.
- **Search annotations**: Search panel › *Zotero annotations*.
- **Drag** an item from the Zotero panel into a note to insert `[@key]`.
- **Click a citation** in a note: opens the reading note if there is one, otherwise the item view. `Alt+click` always opens the item view.
- **BibTeX export**: palette › *Export the bibliography (.bib)*, for LaTeX, Typst or Word.
- **Import into the vault**: the whole library, a collection or a single item becomes a *source* note with its PDF copied into the vault; the vault stays complete without Zotero. Already imported items are recognised by their Zotero ID or citation key, so there are no duplicates.
- **Built-in PDF reader**: *Open PDF* and *Show in PDF* open the PDF in Eloria, in the other pane, at the annotation's exact position. Vault PDFs can be annotated in Eloria too (highlights, comments, page notes, figure capture).
- **Eloria's own library**: *Add a reference* by DOI, title, PDF or BibTeX file, without Zotero. Abstract and keywords are fetched online (Crossref, OpenAlex, Semantic Scholar, DataCite, Europe PMC) or read from the PDF.
- **Around a source**: similar articles, references and citing articles, reliability signals (retractions, journal, citations), research questions that cite it.

## Current limits

- Only the personal library is read, not group libraries.
- Sync reads the whole database (a few seconds for thousands of items); it is not incremental.
- Ink and image annotations are listed but their image is not extracted.
- The `zotero.sqlite` schema is Zotero 7's. If a future version changes it, only `crates/eloria-core/src/zotero.rs` needs adapting, and the local API remains available as a fallback.
