# Les réseaux de fraude sont-ils visibles dans la structure du graphe des transactions ?

## Pourquoi c'est important

Si les comptes mules forment des sous-graphes denses, un modèle de graphe peut les repérer sans données personnelles [@smith2024graph].

## Réponse provisoire

Oui pour la fraude organisée ; la fraude isolée reste difficile. À confirmer sur les données UEMOA ([[Mobile money]]).
